# 指标口径文档（Metrics Dictionary）

> 本文档是驾驶舱全部 KPI 的唯一权威口径。任何看板、智能分析、评测集引用的数字，其公式必须能在本文档找到对应条目；代码实现见 `src/metrics/calculateMetrics.ts`（两者不一致时以本文档为准并提 issue 修正代码）。

## 通用过滤规则

所有指标在计算前先按以下维度过滤数据（下同）：

- **平台**（天猫 / 京东 / 抖音电商 / 自营小程序）
- **店铺**（storeId）
- **品类**（categoryId）

品类过滤采用**比例分摊法**：运费与优惠金额按"过滤后商品小计 / 订单商品总小计"的比例分摊到订单 GMV，保证各品类 GMV 之和等于全店 GMV。

## 时间范围与基准期

| 筛选范围 | 对比基准期 | 展示标签 |
|---------|-----------|---------|
| 单日 | 前一日同期 | 较昨日同期 |
| 2–7 天 | 等长前 7 天 | 较前7天 |
| 8 天及以上 | 等长前 30 天 | 较前30天 |

实现：`comparisonFilters()`。变化率 = (本期值 − 基准值) / 基准值。

## KPI 口径

### 1. GMV（商品交易总额）

- **公式**：`Σ(订单商品小计 + 运费 − 优惠金额)`，按品类过滤时分摊
- **粒度**：订单 × 支付时间
- **计入条件**：状态为 `paid` 或 `fulfilled`，且 `paidAt` 落在筛选范围内
- **排除**：`pending` / `cancelled` / `refunded` 订单不计入

### 2. 净销售额（Net Sales）

- **公式**：`GMV − 退款金额`
- **退款计入条件**：退款单状态 `approved` 或 `completed`，且退款创建时间落在筛选范围内（不是订单支付时间）
- **说明**：退款按品类过滤时同样做比例分摊

### 3. 订单量（Order Count）

- **公式**：满足 GMV 计入条件的订单去重计数（按订单 ID）
- **注意**：一个客户当日多笔订单计为多笔

### 4. 支付转化率（Conversion Rate）

- **公式**：`去重支付买家数 ÷ 访客数`
- **访客数**：流量记录（traffic）中 `visitors` 字段求和，按记录时间戳过滤
- **边界**：访客数为 0 时返回 0（不返回 NaN）

### 5. 客单价（AOV, Average Order Value）

- **公式**：`GMV ÷ 订单量`
- **边界**：订单量为 0 时返回 0

### 6. 毛利率（Gross Margin Rate）

- **公式**：`(净销售额 − 商品成本) ÷ 净销售额`
- **成本口径**：`Σ(商品数量 × unitCost)`，仅统计满足 GMV 条件的订单中被过滤命中的商品项
- **边界**：净销售额为 0 时返回 0

### 7. 退款率（Refund Rate）

- **公式**：`退款金额 ÷ GMV`
- **分子分母时间窗不同**：GMV 按 `paidAt`、退款按 `refund.createdAt` 归期——因此该比率可能超过 100%（历史订单大额退款），属正常现象
- **边界**：GMV 为 0 时返回 0

### 8. 目标达成率（Target Achievement Rate）

- **公式**：`GMV ÷ 目标 GMV`
- **目标来源**：`dataset.targets` 按日期键求和（日期键 = 本地时区 YYYY-MM-DD）
- **边界**：目标为 0 时返回 0

## 异常检测口径

实现：`src/metrics/detectAnomalies.ts`。每条规则的触发条件、影响金额算法如下：

| 规则 | 严重度 | 触发条件（与昨日同期比） | 影响金额算法 |
|------|--------|------------------------|-------------|
| 退款率异常上升 | critical | 变化率 ≥ +30% 且绝对值 > 8% | `GMV × (本期退款率 − 昨日退款率)` |
| 支付转化率下降 | warning | 变化率 ≤ −15% | `GMV × (昨日转化率 − 本期转化率)` |
| 目标达成进度落后 | warning | 达成率 ≤ 当日时间进度 − 10pp | `GMV × (时间进度 − 达成率)` |
| 库存风险 | warning | 可用天数 < 3 天 | （无金额，提示补货） |

时间进度 = 当日已过分钟数 ÷ 全天分钟数。

## 数据模拟边界

- 数据集为**模拟数据**（`src/data/generateDataset.ts`），不对应真实商家
- 实时模块每 3 秒模拟一次订单/退款事件（`eventSimulator.ts`），暂停后停止更新
- 7 天预测使用历史周度基线 + 近期趋势外推，仅供演示，不构成经营承诺
